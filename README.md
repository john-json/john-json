### `~/about`

I build native **macOS apps** and desktop customization tools.  
My design system — **ilstr01** — runs across everything I make:  
themes, configs, widgets, and app UIs.

Currently working on:
- 🧩 **CustoHub** — hub for icons, wallpapers & customization
- 🖱 **ContextMenuPlus** — macOS context menu extension
- 🎛 **MenubarPlus** — advanced menubar utility
- 🔩 **Docksmith** — Dock customization for macOS
